EOL error uses an alarm at 80.5 % SOH (batch-3 cells stop at 80.0–80.15 %, so a strict 80 % crossing never occurs there). It is computed on raw, unsmoothed per-cycle estimates, so a single noisy low estimate triggers an early alarm. A **missed alarm** = the cell truly crossed the alarm level but the estimate never did (the model is optimistic near end of life) — the dangerous failure mode for a BMS. A **false alarm** = the estimate crossed the alarm level but the cell never did (premature replacement).
